# **Voizzy Design Guidelines**

## **Overall Feel**

* Clean, modern, mobile-first

* Voizzy-branded colors for Free/Basic users (no customization)

* Simple UX: prioritize clarity and speed

## **Embeds**

* Wall of Love iframe must be fully responsive

* Use basic card-style layout for testimonials

## **Testimonials**

* Show name, text content, optional title

* Approve/delete controls (dashboard only)

## **Admin Interface**

* Light UI

* Only key metrics and user activity list

### **Colors**

* Use 3 preset schemes:

  * Ocean Blue: `#0077CC` primary, `#F0F4FA` background

  * Sunset Orange: `#FF6B35` primary, `#FFF3EC` background

  * Modern Gray: `#333333` primary, `#FAFAFA` background

### **Typography**

* Font: `Inter` (Google Font)

* Headings: Bold, 24px+

* Paragraphs: 16px regular

* Labels: Uppercase, 12px semi-bold

### **Buttons**

* Primary button: Filled, rounded-xl, hover with 10% darken

* Secondary: Border only, same color

* Disabled: Grayed with `opacity-50`

### **Layout & Spacing**

* Section padding: `py-12 px-6`

* Component spacing: `gap-6` (grid/flex)

* Container max-width: `1024px`, centered  
* Grid-based layout for dashboard

* Mobile-first for testimonial submission form

### **Form Elements**

* Rounded-md input fields with subtle shadows

* Clear focus state (`outline-blue-500`)

* File uploader: Drag & drop with fallback button
